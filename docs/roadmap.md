# Дорожня карта ViloreHome

План на найближчі чотири тижні розвитку каталогу товарів для дому. Тижні наведені відносно поточного етапу проєкту; конкретні дати та обсяг можуть уточнюватися під час реалізації.

## Тиждень 3 — детальний endpoint товару

- Додати `GET /api/Items/{id}` для отримання одного товару за його ідентифікатором.
- Повертати `404 Not Found`, якщо товару з таким ідентифікатором немає.
- Перевірити endpoint через Swagger і додати перевірки для успішної відповіді та відсутнього товару.

**Результат:** клієнт може завантажити окрему позицію каталогу, а API коректно обробляє невідомий ідентифікатор.

## Тиждень 4 — базова авторизація

- Додати автентифікацію користувачів із токенами Bearer.
- Визначити мінімальні ролі: покупець і адміністратор.
- Захистити операції керування каталогом; публічний перегляд товарів залишити доступним без входу.
- Перевірити доступ для авторизованого користувача, адміністратора та анонімного запиту.

**Результат:** адміністративні операції доступні лише уповноваженим користувачам.

## Тиждень 5 — CRUD товарів

- Реалізувати створення, перегляд, редагування та видалення товарів через API.
- Додати перевірку вхідних даних, зокрема назви, категорії та ціни.
- Дозволити змінювати каталог лише адміністратору.
- Перевірити типові сценарії та відповіді API для некоректних даних і відсутніх товарів.

**Результат:** адміністратор може повністю керувати товарами каталогу через API.

## Тиждень 6 — інтеграція та стабілізація

- Під'єднати перегляд і адміністративні сценарії фронтенду до нових endpoint-ів.
- Додати обробку станів завантаження, помилок і завершення сесії.
- Перевірити взаємодію фронтенду, API та SQLite у наскрізних сценаріях.
- Оновити документацію API та інструкції запуску, якщо змінилися налаштування.

**Результат:** основні сценарії каталогу працюють від інтерфейсу до бази даних.
