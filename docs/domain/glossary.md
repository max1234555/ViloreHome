# Глосарій ViloreHome

1. **Домен** — предметна область, для якої створюється система; тут це онлайн-продаж товарів для дому.
2. **Піддомен** — окрема частина предметної області, наприклад каталог, замовлення або склад.
3. **Bounded context (обмежений контекст)** — межа, всередині якої терміни та правила мають однозначний зміст і належать конкретній моделі.
4. **Модульний моноліт** — один застосунок, розділений на модулі з чіткими межами та відповідальністю.
5. **Сутність (Entity)** — об'єкт домену з ідентичністю та життєвим циклом, наприклад `Order`.
6. **Агрегат (Aggregate)** — група пов'язаних об'єктів, зміни якої проходять через корінь агрегату. У прототипі `Order` керує своїми `OrderItem`.
7. **Інваріант** — правило, яке має залишатися істинним після кожної доменної операції, наприклад резерв не перевищує наявний залишок.
8. **Контекстна мапа (Context map)** — схема bounded contexts і залежностей між ними.
9. **Ціна-знімок (price snapshot)** — ціна товару, зафіксована в позиції замовлення на момент його оформлення.
10. **Резерв товару** — кількість товару, тимчасово відведена під замовлення і недоступна для інших покупців.
